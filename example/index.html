Named Sources (multiple snippet files)

With a manifest registered via <meta name="snippet-sources" content="./sources.json">, each viewer can pull from a different file by naming a source. The manifest here maps frontend → frontend-snippets.json and java → java-snippets.json — both produced by the snippet-extractor from the smoke-test fixtures.

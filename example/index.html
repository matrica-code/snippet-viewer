Extractor Marker Features

These snippets are produced by the snippet-extractor from a single annotated Example.java, showing two marker capabilities.

Reusing one class across snippets

Two markers back the same class; a scoped // extract-code ignore overview hides one method from the overview snippet while detail keeps it — no need to duplicate the class: 

// extract-code overview
// extract-code detail
public class ExampleClass {
    public void basic(Map<String, String> store) {
        store.put("greeting", "hello");
    }

    // extract-code ignore overview
    public void advanced(Map<String, Integer> store) {
        store.merge("visits", 1, Integer::sum);
    }
}

Grouping loose statements with a terminator

A run of sibling statements the AST wouldn't bundle on its own is grouped by closing the marker with // extract-code end <name>. The trailing service.flush() falls outside the terminator and is excluded: 

// extract-code data-storage
service.set("org.group", "key", "value");
String val = service.get("org.group", "key");
// extract-code end data-storage

service.flush();
